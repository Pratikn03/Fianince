# Analysis plan

All confirmation outputs are generated by scripts under
`studies/next_stage_validation/scripts/` and are written to that study's
`results/` directory.

1. Keep the frozen master studies and their denominators unchanged.
2. For agents, compare paired tapes episode by episode. Report means,
   event-rate proportions, and deterministic bootstrap intervals for
   neural-minus-adaptive gain. Never pool episodes across training seeds as if
   they were one independent sample; seed-level summaries remain separate.
3. For observations, resample complete episodes, not rows from a long trace.
   Report coverage, decisive fraction, wrong-confident fraction, unresolved
   fraction, and mean slope separately.
4. For interventions, report event rate, mean gain, and mean drawdown for each
   policy on the same tapes. The event rate is not a real-market probability.
5. For public Binance klines, use chronological 60/20/20 train/validation/test
   splits. The current data support descriptive OHLCV calibration only; no L2
   fill or cancellation claim is permitted.
6. Preserve all failed and adverse outputs. Any change to a configuration or
   stopping rule creates a new versioned result rather than replacing an old
   one.

The current result files are:

- `matched_agent_results.json`
- `matched_agent_analysis.json`
- `observation_benchmark.json`
- `intervention_results.json`
- `kline_calibration_summary.json`

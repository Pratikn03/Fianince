## Safe current positioning

The defensible current contribution is a reproducible evidence-boundary and
failure-analysis package combining formal synthetic constraints, noisy/dependent
observation stress tests, matched small-policy comparisons, conditional
intervention tests, and a public depth-band/trade-tape transfer layer. That
combination may be useful, but the repository does not establish that it is
novel. A human reviewer must inspect publication dates, overlapping assumptions,
technical lemmas, and venue-specific priority standards.

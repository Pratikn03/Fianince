# Data-access request drafts (not sent)

Two drafts for the one gap that public data cannot close: whether class persistence is learning memory or slow position
turnover (Paper 1; Test C2's registered jackknife secondary), and a direct measurement of the feedback term. Both need
**class-tagged order flow**, which the theory's tagged contract assumes and which Binance does not publish. Review,
edit and send yourself, ideally with a professor as co-signer; nothing has been sent.

## 1. CFTC (academic research access)

**To:** CFTC Office of the Chief Economist (research data programme; check the current contact on cftc.gov)
**Subject:** Research data request: trader-class order flow in futures markets (MNSU)

Dear Office of the Chief Economist,

I am an undergraduate researcher at Minnesota State University, Mankato, working with [professor name] on how much a
supervisor can learn about algorithmic traders from market data. Our theory predicts that prices reveal traders' memory
only through a merged measure, while trader-class flow reveals it at the ordinary statistical rate. Using the public
Commitments of Traders reports we found that class-level positions restrict a persistence parameter that prices cannot
bound, but weekly positions cannot distinguish trading memory from slow position turnover.

We would like to ask whether daily or intraday order flow aggregated by trader class (for example, the classes of the
Disaggregated or Traders in Financial Futures reports) is available to academic researchers for a small set of
contracts, under whatever confidentiality terms apply. Our analysis code and pre-registered test specifications are
public at github.com/Pratikn03/Fianince, and we would register the analysis before receiving any data.

Thank you for considering this request.

[Name, affiliation, professor co-signer, contact]

## 2. A crypto exchange or data vendor (tagged flow)

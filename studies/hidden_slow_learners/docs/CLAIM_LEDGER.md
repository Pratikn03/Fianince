# Claim ledger

| Claim | Evidence | Status / restriction |
|---|---|---|
| The model is stable exactly when a+Q<1. | Positive-systems specialization with a proof; eigenvalue checks. | Established mathematics specialized here; not a new law of finance. |
| For every finite K there are opposite-stability models with equal k[0:K] and h[0:K+2]. | Barycentric/Vandermonde construction and proof; 112 exact rational witnesses. | Candidate finance-specific contribution; related to classical truncated moment ambiguity. |
| The same finite input sequence yields the same finite price path. | Convolution identity; 336 synthetic common-shock checks. | Zero initial learning state and the specified time window only. |
| A known valid minimum learning rate gives feedback bounds. | Finite geometric sums and tail domination; proof and 432 exact panel checks. | Simple outer bounds, not the optimal full moment-feasibility bound. |
| One-rate extrapolation can falsely imply safety. | Exact heterogeneous witness; general Jensen lower-bound interpretation. | A one-rate point estimate is not a certificate under mixed rates. |
| No incorrect confident rate-aware decisions occurred in the full run. | 21,600 measurement datasets; 86,400 decisions; separate reconstruction verifier. | Finite synthetic observation experiment. Some datasets receive no decision. |
| Gaussian simultaneous confidence is at least 95% under assumptions. | Bonferroni argument over eight statistics. | Known independent tap-noise standard errors, valid rate floor, fixed model, four predeclared horizons. |
| The result is reproducible. | Tests, exact verifier, measurement verifier, clean-directory rerun. | Internal reproducibility established here; an independent external researcher has not replicated it. |
| This changes global financial supervision or predicts crises. | None. | Not claimed. Requires validated measurement, economic models, observed data, and external review. |
| This is globally novel or paradigm-shifting. | Focused primary-source search only. | Not established. The new-to-project construction may overlap existing positive-realization or moment-identification work. |

The most important information asymmetry is intentional and explicit: the non-identifiability result uses short price responses, whereas the noisy diagnostic experiment uses controlled return-kernel measurements and a rate floor. Treating those as the same dataset would be an invalid claim.

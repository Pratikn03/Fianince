# A restricted separation with a net financial decision

Start with `PROOF.tex` and `LITERATURE.md`. This package supplies a written
finite-horizon theorem, adversarial algebra/accounting checks, a synthetic
after-cost decision experiment and a Colab results-return notebook. It does
not certify novelty, independent correctness review, real-market validity,
or completion of the full manuscript's open theorem. No Lean proof is claimed.

The new institution is a price-taking inventory-warehousing desk paid a quoted
service premium after settlement. This is distinct from the preceding
expected-log investor experiment and from a venue that changes market feedback.
It buys once, holds 60 model minutes, closes, and pays execution, carry and
information fees. The learning bill reduces both available collateral and
net service profit. Conditional mean-zero future flows are assumed; no extra
return-training or validation observations are used.

The response certificate uses all H taps in N fixed reset experiments. The
cohort test receives the same observations. General positive cohorts have no
minimum adaptation rate, but plant/reset/noise/stationarity/total-feedback
bounds are assumed. This is not a certificate from an ordinary public tape.

The hard pair has two cohorts in BOTH worlds, with matching rate moments
through degree two and a response gap of order delta^3. A fixed-error known-
pair test therefore needs order delta^-6 reset experiments. A direct finite-H
financial decision bound has no delta dependence. This does not say that
learning an observable response vector is that hard or that all probe designs
obey the same bound. The no-data comparison is the sharp class-robust optimum.

The Gaussian linear-functional baseline is EXACTLY the proposed certificate.
The estimator is standard. The candidate addition is the explicit financial
cost/capital theorem and its limited demonstration, subject to novelty review.

Run locally:

```bash
python -m pip install numpy scipy pandas matplotlib
python run.py --profile full --out /absolute/new/output
```

The output folder and ZIP include the frozen-design hash, complete sensitivity
tables, exact-pair requirements, positive and negative net values, assumption
failures, cash-flow audit, test log, source snapshot and SHA-256 manifest.
Nothing automatically writes empirical claims into the older manuscripts.

`PROTOCOL.md` was frozen before this package's first run, after the preceding
project experiments. This is an exploratory local design, not an independent
preregistration. Prices and fees are illustrative; no actual exchange cost,
market stability or equilibrium welfare result is inferred. Code checks are
not a substitute for reading the analytic proof or for specialist review.

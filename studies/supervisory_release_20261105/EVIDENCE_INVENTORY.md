## Unfilled empirical quantities

1. Audited mapping from a reported class to the target that can actually be halted.
2. A validated observation model translating tagged flows into a post-action feedback-budget confidence bound.
3. An empirically justified response allowance for both available actions over the declared holding horizon.
4. Disclosure acquisition/compliance costs in compatible units.
5. Intervention utility and implementation costs, evaluated against feasible alternatives with equal information.

These gaps are represented as explicit assumptions and sensitivity parameters, not claimed to be measured. A new real-market or known-mechanism tagged-flow experiment should address these specific objects before a market-benefit claim is made.

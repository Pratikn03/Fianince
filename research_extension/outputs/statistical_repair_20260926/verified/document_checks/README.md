# Document verification scope

26 September 2026. Main document: 62 pages. Mathematical supplement: 26 pages.

- The built-in desktop compiler reported success for both sources.
- Local pdfLaTeX builds used three passes. Final logs contain no matches for
  `Overfull`, `undefined`, `Warning`, or `Error`.
- All 62 main-paper pages were inspected as contact-sheet thumbnails for gross
  layout defects. Main pages 1, 9, 22--25, and 41 were also inspected at higher
  resolution. Supplement pages 17 and 21 were inspected at higher resolution.
- A funded-table margin overflow was corrected using wrapped headers; the
  accompanying plot width was reduced. The regenerated statistical tables and
  plots were checked for legibility, labels and numerical consistency.
- Contact-sheet inspection is not a line-by-line proof review. Some float and
  reference pages retain generous whitespace; this is not a complete editorial
  redesign or a claim that every page has been checked at print resolution.
- Clean-copy text/layout extraction is checked by the final verification
  recorder. Text/layout equality does not establish pixel or byte identity.

The saved local build logs and rendered previews supplement the programmatic
receipt. Human mathematical, statistical, economic and publication review
remain pending.

\section{Machine-checked declarations}\label{app:verification}

The table lists, for each main result, the Lean~4 declarations that check it and what is proved only on paper. The project builds against a pinned Mathlib. For this version the axioms of the headline declarations were printed again (\texttt{\#print axioms}): each depends only on \texttt{propext}, \texttt{Classical.choice} and \texttt{Quot.sound}. A machine check confirms the formal statement, not that it matches the prose. The prose statements above say where the two differ.

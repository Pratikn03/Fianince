\section{Machine-checked declarations}\label{app:verification}

The table lists, for each main result, the Lean~4 declarations that check it and what is proved only on paper. The project builds against a pinned Mathlib across 142 modules comprising 1,242 named mathematical declarations, with no \texttt{sorry} placeholders. For this version the axioms of the headline declarations were verified again via automated kernel extraction: each depends strictly and exclusively on Lean's standard foundational axioms (\texttt{propext}, \texttt{Classical.choice} and \texttt{Quot.sound}). A machine check confirms the formal statement, not that it matches the prose. The prose statements above say where the two differ.

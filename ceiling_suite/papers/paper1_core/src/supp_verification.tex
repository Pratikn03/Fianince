\section{Machine-checked declarations}\label{app:verification}

The table lists, for each main result, the Lean~4 declarations that check it and what is proved only on paper. The project builds against a pinned Mathlib and has 1,206 named declarations in 138 modules, with no \texttt{sorry}. A full build on 13 November 2026 (Lean 4.34.1, Mathlib commit \texttt{d13f23b}) passed, together with the axiom audit below; the receipt, which records the SHA-256 hash of every source file, is \nolinkurl{research_extension/current_manuscript_lean_20261008/formal_verification_receipt.json}. An axiom audit of every named declaration finds only Lean's three standard axioms (\texttt{propext}, \texttt{Classical.choice} and \texttt{Quot.sound}). A machine check confirms the formal statement, not that it matches the prose. The prose statements above say where the two differ.

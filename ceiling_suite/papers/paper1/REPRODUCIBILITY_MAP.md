# Source of every number

The replication package contains numbered Colab notebooks and
stand-alone scripts; its README lists them in run order. “Part $N$”
below and in table notes refers to notebook $N$ (Part 1: theorem checks
and spot tests; Part 2: BTCUSDT futures depth; Parts 4–13: the
cross-section, replications, fresh-day tests, second venues, the CFTC
test, the certified guard and post-hoc checks). Result identifiers such
as `X6` or `U6` name the JSON file that the notebook writes. “Kind”
distinguishes closed-form or simulation results (recomputed), results
from public market data (real data), and audits.

## Title
Observationally Equivalent Algorithms: What Prices Reveal About Trader Populations, and What Supervisors Need

## Authors (in this order)
Pratik Niroula (Minnesota State University, Mankato); Prashant Niroula (Tribhuvan University);
Sujan Khatiwada (Minnesota State University, Mankato). Submitter: Pratik Niroula.

## Abstract
Algorithmic traders read prices and, by trading, move them. We ask what the public record reveals about the population of such traders, and what supervisors need beyond it. When traders respond to a common public signal, the population affects prices, order flows and dealer inventories only through its aggregate feedback response, also in an inventory equilibrium. Learning anything finer is expensive: telling apart K trader types whose rules lie within Δ of one another needs of order Δ^-(4K-2) observations, an order attained for linear memory rules. With Gaussian news, what a record reveals about two candidate populations equals the cumulative forecast loss from confusing them. A uniform cut in feedback can therefore be set from prices, and without class tags it is the minimax policy; a targeted restriction cannot be set from prices. Calibrated to Taiwan's tagged exchange flows, prices alone pin down the effect of a uniform cut but cannot attribute feedback to the trading classes. Class tags restore targeting only if relabeling is costly; an audit trail linking accounts to owners does not need that. Without tags, more surveillance data can leave the supervisor less informed, because algorithms that fear targeting crowd together. Core steps are checked in Lean 4.
